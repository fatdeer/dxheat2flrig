# Chrome/Chromium/Edge-Extension to set the VFO on your Rig with one Click at dxheat.com on the QRG

Now also available as Firefox-Extension. Check "Releases" on the right.

Quick hack / No warranty :)

Prerequisites:
* TRX :)
* FLRig (Default XML-RPC-Port: 12345 / Could be customized via Options)
* Chrome/Chromium **or** Microsoft Edge (version 88 or newer, Manifest V3 support)

Howto (Chrome/Chromium):
* ~~Simply edit "bg.js" an adjust the Port/URL of your flrig instance (Line 1)~~
* Go to Chrome Extensions (`chrome://extensions/`) and turn "Dev Mode" (upper right) on.
* Point to "Load unpacked extension" (upper left)
* Choose Folder with Extension (this folder)
* Go to Options-Page of the Extension (tnx to DG7PX for that) and adjust URL/Port of your FLRig
* Enjoy

Howto (Microsoft Edge):
* Open `edge://extensions/`
* Toggle "Developer mode" on (lower-left corner)
* Click "Load unpacked"
* Choose Folder with Extension (this folder)
* Right-click the extension icon -> "Extension options" and adjust URL/Port of your FLRig
* Enjoy

### Plugin is under development. If you wish to upgrade simply **remove** the old Version (Chrome / Edge / Extensions / Remove) and register the new one
